# API Films

API REST de gestion de films (films, réalisateurs, genres, avis, utilisateurs).

Projet Backend – CPNV, classe SI-CA2a – 2026-2027

## Technologies

- Node.js / Express
- MySQL
- Authentification par token (JWT)
- Tests : Postman
- Documentation : Swagger
